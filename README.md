# Susmitha — 4th November

Hockey game classification dataset and Gini impurity analysis.

## Files
- `hockey_game_dataset.csv` — hockey game dataset (14 records, 5 columns)
- `Susmitha_Hockey_Notebook.ipynb` — notebook evaluating unique binary splits using Gini impurity
- `susmitha_hockey_gini_results.csv` — calculated Gini split results

## Run
Keep the notebook and dataset in the same folder, then open `Susmitha_Hockey_Notebook.ipynb` in Jupyter Notebook or Google Colab.
